# Changelog — IDPG Core

Все заметные изменения плагина фиксируются в этом файле.
Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версионирование — [SemVer](https://semver.org/lang/ru/).

## [1.0.8] — 2026-09-01

### Добавлено
- `uninstall.php` — очистка при удалении плагина: опции (`idpg_social_auth_settings`, `idpg_roles_version`, `idpg_maintenance_*` и др.), транзиенты (`idpg_social_state_*`, `idpg_vk_pkce_*`, lock миграции), user meta (привязка соцсети, аватары, данные организатора, избранное), cron-задача синхронизации билетов. Данные событий (`_idpg_*` post meta) по умолчанию сохраняются; полная зачистка — константой `IDPG_CORE_UNINSTALL_WIPE_DATA`.
- `languages/idpg-core.pot` — шаблон переводов (461 строка, text domain `idpg-core`).
- `bin/make-pot.js` — генератор POT без внешних зависимостей (Node.js).
- Страница-мост `/auth/callback/vk/` — завершение OneTap-входа: SDK обменивает код на токен в браузере, токен передаётся в REST `idpg/v1/auth/vkid`.
- Подсказка на странице настроек соц-авторизации с точным доверенным Redirect URI приложения VK.
- Проверка возможности полного сброса rewrite-правил при смене версии маршрутов (`idpg_social_auth_rewrite_flushed` v5).

### Исправлено
- VK ID OneTap: устранена ошибка «New tab has been closed» — в `Config.init()` передаётся `mode: VKID.ConfigAuthMode.Redirect` (ключ именно `mode`/ConfigAuthMode, а не `responseMode`); авторизация выполняется редиректом в той же вкладке, новая вкладка не открывается.
- Страница-мост VK: конфигурация SDK синхронизирована с виджетом (`mode=Redirect`).
- Редиректы по ролям после входа: подписчики → `/lk/`, организаторы → админка, остальные → главная.

## [1.0.7] — 2026-08-29

### Добавлено
- Провайдер **Яндекс ID** (OAuth 2.0: oauth.yandex.ru / login.yandex.ru) и маршрут `/auth/yandex/`.
- Общая страница настроек «Настройки → Социальная авторизация» (VK + Яндекс).

### Изменено
- Версия rewrite-правил поднята до 5 (новые маршруты соц-авторизации).

## [1.0.6] — 2026-08-26

### Добавлено
- OneTap-виджет VK ID на `/login/` (официальный `@vkid/sdk` 2.6.8, низкокодовый режим).
- Классический OAuth-коллбэк виджета: обработка не-серверного state через страницу-мост.
- Скрипт `vkid-onetap.js` — рендер виджета, обработка ошибок, обмен кода и вход через REST.

### Изменено
- Кнопка «Войти через VK ID» заменена виджетом OneTap (дублирующая ссылка скрыта).

## [1.0.5] — 2026-08-20

### Добавлено
- Rate limiter форм входа/регистрации (защита от брутфорса).
- Кастомные HTML-письма авторизации (`class-auth-emails.php`).
- Изоляция контента организатора: свои вложения в медиатеке, свой список событий в админке.

### Изменено
- Роли: версия capabilities поднята до 5 — организаторам добавлены права удаления опубликованных/личных событий и полный набор прав на площадки; подписчикам — `upload_files` (аватар в ЛК).

### Безопасность
- Серверная проверка чекбокса оферты при регистрации.
- Проверка текущего пароля при смене в ЛК, `wp_destroy_other_sessions()` после смены.
- Nonce-проверка POST/PUT запросов ЛК.

## [1.0.4] — 2026-08-14

### Добавлено
- Личный кабинет подписчика `/lk/`: профиль, статистика, смена пароля, аватар.
- REST-эндпоинты: `GET/PUT /user/profile`, `GET /user/stats`, permission `can_access_lk()`.
- Автосоздание страниц `/login/`, `/lk/`, `/terms/`, `/privacy/`.

### Изменено
- Редирект подписчиков после входа и при попытке входа в админку — на `/lk/`.

## [1.0.0 – 1.0.3] — 2026-06-01 … 2026-08-10

### Добавлено
- CPT `event` (slug `/afisha/`) и `venue`, таксономии: `city` (иерархическая), `event_category`, `age_rating`.
- Мета-поля на Carbon Fields: детали события, сеансы, билеты, данные площадки; единый префикс `_idpg_` + REST-мета.
- Многогородская механика: фильтрация архивов по cookie, город в URL (DVHAB-стиль), виджеты «Выбор города» и «Календарь событий».
- Избранное (user meta + REST + счётчик), страница `/lk/favorites/`.
- Счётчики просмотров/кликов, экспорт iCalendar (.ics).
- Система баннеров (позиции middle/bottom, UTM, период показа) и баннер текущего события.
- Синхронизация статусов билетов с внешним API агрегаторов (WP-Cron, каждые 3 часа) и email-уведомления автору.
- Режим «Сайт в разработке» (HTTP 503, настройки в админке, доступ по cookie).
- REST API `idpg/v1`: события, площадки, города, категории, рейтинги, создание/редактирование площадок.
- Роль `event_organizer`, миграции меты (+ WP-CLI команда `wp idpg migrate-meta`), гео-фасад.
- Провайдер VK ID (OAuth 2.1 Authorization Code + PKCE через id.vk.com) и маршруты `/auth/vk/`, `/auth/callback/{provider}/`.
