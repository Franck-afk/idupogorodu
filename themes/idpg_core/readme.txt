Тема для проекта ИДПОГОРОДУ — афиша мероприятий.

== Description ==

Тема разработана для сайта ИДПОГОРОДУ (idupogorodu.ru) — платформы афиши мероприятий.

== Installation ==

1. В панели управления перейдите в раздел Внешний вид > Темы и нажмите кнопку Добавить.
2. Нажмите Загрузить тему и выберите .zip файл темы. Нажмите Установить.
3. Нажмите Активировать для использования темы.
