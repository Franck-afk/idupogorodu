Документация для нейросетей

Артефакты, оптимизированные для LLM и AI-агентов: индекс по стандарту llms.txt, полный технический контекст одним файлом и правила работы с кодовой базой.

Доступные артефакты

llms.txt

Индекс по стандарту llmstxt.org: H1, блок-описание и курируемые ссылки с аннотациями. Точка входа для любого агента.

docs/web/llms.txt

llms-full.txt

Полный технический контекст одним файлом: структура, контракты классов, хуки, инварианты, команды, глоссарий. Скачать и скормить в контекст целиком.

docs/web/llms-full.txt

AGENTS.md

Корневые правила проекта для AI-агентов: запреты на удаление/перезапись, стандарты WordPress, требования к безопасности, Spec Driven-процесс.

AGENTS.md (корень проекта)

HTML-документация

Человекочитаемая версия того же материала с навигацией. Для агентов с веб-доступом — можно читать по ссылкам из llms.txt.

docs/web/index.html

Как использовать в промпте

Пример контекста для LLM
Ты работаешь с WordPress-плагинами проекта «Иду по городу».
Перед правками изучи docs/web/llms-full.txt — там контракты
классов IDPG_Banner_Settings / IDPG_Current_Event_Banner,
инварианты безопасности и точки расширения.

Правила: не удаляй работающий код без явного запроса;
новые функции — с префиксом idpg_; правки настроек баннера
только через defaults/sanitize/get_* с clamp.
