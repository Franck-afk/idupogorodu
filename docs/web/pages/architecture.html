Структура проекта

Портал-афиша «Иду по городу»: мультигородская платформа событий на WordPress. Ниже — как устроен проект и какие компоненты затронули доработки.

Плагины

idpg-core v1.1.2

Ядро: 36 классов — CPT событий и площадок, таксономии, роли, REST API (36 маршрутов idpg/v1), мультигород, авторизация, баннер, календарь, избранное.

idpg-auth v1.0.0

OAuth-вход через ВКонтакте, Яндекс ID и MAX. Журналы, антибрутфорс, КоАП-режим. 11 классов.

idpg-city-admin v1.0.1

Админ-раздел «Иду по городу»: страница настроек с вкладками, «Конфиденциальность» (152-ФЗ), «Отклонить событие», «Области виджетов».

idpg-maintenance v1.0.0

Режим «Сайт в разработке»: заглушка 503, пароль доступа, белый список IP, отсчёт до запуска.

Тема idpg_core

КомпонентНазначение

assets/css/templates.cssДизайн-система: 101 CSS-токен, карточки событий, чипы

Ключевые зависимости

Carbon Fields 3.6

Мета-поля событий (~35) и площадок, реквизиты организатора. Composer-зависимость в idpg-core.

Yoast SEO

JSON-LD Event/Place, OpenGraph, крошки — через IDPG_SEO_Integration.

WooCommerce

Роль customer, HPOS-совместимость idpg-auth.

Правило проекта. Бизнес-логика — в idpg-core; тема отвечает только за представление. Новый код — через хуки, с префиксом idpg_, без удаления работающего кода без явного запроса.
