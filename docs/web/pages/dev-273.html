Удаление страницы «Настройки главной»

Дублирующая страница управления видимостью секций главной устранена целиком: все 5 секций теперь показываются всегда, настройка через чекбоксы удалена из темы и из админки плагина.

Проблема

Страница «Внешний вид → Настройки главной» в теме дублировала функционал вкладки «Главная (Блоки)» в плагине idpg-city-admin. Владелец решил удалить настройку видимости секций целиком — секции главной должны отображаться всегда.

Что удалено

КомпонентЧто было удалено
Тема idpg_core Файл inc/home-sections.php (148 строк): регистрация опции idpg_home_sections, страница админки, функции idpg_home_sections_list() и idpg_home_section_enabled()
functions.php require_once удалённого файла
front-page.php 5 условных обёрток if ( idpg_home_section_enabled( ... ) ) — секции «Сегодня», «Выходные», «Бесплатные», «Популярные», «Лента»
idpg-city-admin Вкладка «Главная (Блоки)»: пункт массива $tabs, панель <section>, метод render_glavnaya_tab(), редирект старого URL idpg-home-sections, скрытие подменю
База (стенд) Опция idpg_home_sections — 1 строка в wp_options
