Обратные пробы

По процессу проекта критерий должен ловить дефект, а не описывать текущее поведение. Ключевые пробы:

Override не применился

Если get_banner_title() не читается в рендере — в HTML остаётся название события, тест падает на assertStringNotContainsString.

Fallback сломан

Если при пустых полях баннер не берёт данные события — тест падает на assertStringContainsString( 'Название события из БД' ).

Чекбоксы вернулись

Если секция полей с чекбоксами reappeared в форме — test_admin_tab_has_no_field_checkboxes падает.

Высота не проброшена

Без --idpg-banner-h:Npx в HTML тест сверки падает — высота из поля не доходит до CSS.
