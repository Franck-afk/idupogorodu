Отдельная страница «Области виджетов»

Новый пункт подменю «Иду по городу → Области виджетов» со собственной страницей управления: создание, редактирование и удаление областей виджетов с выбором места вывода и условий показа — в визуальном стиле Clearfy Pro.

Регистрация меню

class-settings-page.php — register_page()
public function register_page() {
	add_menu_page(
		__( 'Иду по городу', 'idpg-city-admin' ),
		__( 'Иду по городу', 'idpg-city-admin' ),
		'manage_options',
		self::PAGE_SLUG,
		array( $this, 'render_page' ),
		'dashicons-admin-generic',
		25
	);

	add_submenu_page(
		self::PAGE_SLUG,
		__( 'Области виджетов', 'idpg-city-admin' ),
		__( 'Области виджетов', 'idpg-city-admin' ),
		'manage_options',
		self::WIDGET_AREAS_SLUG,          // idpg-widget-areas-manage
		array( $this, 'render_widget_areas_page' )
	);
}

Методы страницы

МетодНазначение
render_widget_areas_page()Полный рендер страницы: заголовок, плашка уведомления, карточка формы, карточка списка областей
handle_widget_areas_post()Обработка POST на admin_init: добавление, обновление, удаление области + очистка sidebars_widgets
render_widget_areas_notice()Плашки «добавлена / обновлена / удалена / не указано название»

Безопасность

  • Nonce: wp_nonce_field( 'idpg_widget_areas_action' ) + wp_verify_nonce() в обработчике
  • Права: current_user_can( 'manage_options' ) — и в рендере, и в обработке
  • Ввод: sanitize_key для slug/position/display, sanitize_text_field для названия, array_map( 'intval' ) для страниц
  • Safelist: значение position/display принимается только из белого списка idpg_widget_areas_positions() / idpg_widget_areas_display_options()

Данные областей

5 позиций вывода

below-header · above-content · event-sidebar · below-content · before-footer

6 условий показа

all · front · page · post · archive · specific (конкретные страницы)

Данные читаются из опции idpg_widget_areas через функции темы (idpg_widget_areas_all() и др.) — дублирования логики нет, страница плагина использует существующий механизм. Каждая область регистрируется как стандартный sidebar idpg-area-{slug} и появляется на экране «Виджеты».

Интерфейс страницы

  • Карточка формы — поля «Название», «Место на фронте», «Показывать», чекбоксы страниц (появляются при условии «Конкретные страницы»)
  • Карточка списка — каждая область: иконка, название, цветные бейджи (позиция / условие / число страниц), кнопки «Редактировать» и «Удалить» с confirm
  • Hover-эффекты — подъём карточки + синяя акцентная полоса слева
  • Sticky-панель сохранения формы
i

Хук экрана страницы (idpg-settings_page_idpg-widget-areas-manage) добавлен в admin_ui_hooks() — общий слой admin-ui.css подключается автоматически.
