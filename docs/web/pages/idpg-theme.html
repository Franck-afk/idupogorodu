Виджеты темы

IDPG_Ad_Ru_Widget

Реклама: код площадки (РСЯ, VK, SMI2, MarketGid, MediaVenus) или баннер-картинка. Медиа-загрузчик, пресеты шаблонов, поле «Позиция» для сортировки.

IDPG_Recent_Events_Widget

Последние события с фильтром по текущему городу (2–10 штук).

IDPG_Subscribe_Widget

Подписка на дайджест: форма с honeypot и согласием 152-ФЗ, отправка через REST idpg/v1/subscribe.

5 позиций

6 условий показа

Данные — в опции idpg_widget_areas; каждая область регистрируется как sidebar idpg-area-{slug}. Управление — на отдельной странице «Области виджетов» в меню «Иду по городу».

Дизайн-система

  • 101 CSS-токен в style.css (--idpg-*): цвета, отступы, радиусы, тени, типографика
  • 25 SCSS-файлов: base/ (сброс, типографика), components/ (кнопки, карточки, формы, чипы), pages/ (главная, афиша, событие), responsive.scss
  • Сборка: npm run watch (sass --watch), npm run check:css — компиляция во временный файл и сверка с эталоном style.css (bin/check-css-build.mjs)
  • Линт: npm run lint:scss (stylelint + recommended-scss)
  • Собранные CSS подключаются с версией через filemtime — автокэш-бастинг при изменениях
package.json — скрипты
"scripts": {
	"watch":             "sass --watch assets/scss/style.scss:style.css --no-source-map",
	"compile:css:temp":  "sass assets/scss/style.scss:style.css.tmp --no-source-map --style=expanded",
	"check:css":         "npm run compile:css:temp && node bin/check-css-build.mjs style.css.tmp style.css",
	"compile:css:apply": "sass assets/scss/style.scss:style.css --no-source-map --style=expanded",
	"lint:scss":         "stylelint \"assets/scss/**/*.scss\""
}
