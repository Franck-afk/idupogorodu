Баннер на главной

Три этапа работ: восстановление стилизации после расхождения CSS и HTML, замена чекбоксов полей на реальные поля ввода данных и сверка «поле формы → вывод в баннере».

Как устроен баннер

Баннер рендерит IDPG_Current_Event_Banner по хуку idpg_banner_position (позиция hero, вызывается в front-page.php). Приоритет — подтверждённые (оплаченные) события: одно — обычный баннер, несколько — карусель с авто-ротацией. Иначе — ближайшее предстоящее событие текущего города с постером.

front-page.php — позиция баннера
<div class="container" style="padding-top: 106px;">
	<?php do_action( 'idpg_banner_position', 'hero' ); ?>
</div>

Этап 2 · Поля ввода вместо чекбоксов

12 чекбоксов «полей баннера» удалены из вкладки «Баннер на главной» — все поля события теперь выводятся всегда. Вместо них добавлена секция «Данные баннера» с реальными полями ввода:

Override-логика в рендере

class-current-event-banner.php — render_single_html()
// Свои заголовок и текст из настроек перекрывают данные события.
$title = IDPG_Banner_Settings::get_banner_title();
if ( '' === $title ) {
	$title = get_the_title( $event );
}

$excerpt = IDPG_Banner_Settings::get_banner_text();
if ( '' === $excerpt ) {
	$excerpt = has_excerpt( $event ) ? trim( (string) get_the_excerpt( $event ) ) : '';

	// Анонс события обрезаем до настроенной длины (0 — без
	// обрезки); свой текст выводим как есть.
	$excerpt_length = IDPG_Banner_Settings::get_excerpt_length();
	if ( $excerpt_length > 0 && mb_strlen( $excerpt ) > $excerpt_length ) {
		$excerpt = mb_substr( $excerpt, 0, $excerpt_length ) . '…';
	}
}

// PHP — inline-переменная на элементе:
return '<a class="idpg-current-event-banner" style="--idpg-banner-h:'
	. esc_attr( (string) $banner_height ) . 'px" href="...">';

/* CSS */
.idpg-current-event-banner { height: var(--idpg-banner-h, 400px); }

@media (max-width: 767px) {
	.idpg-current-event-banner { height: 260px; }  /* перебивает */
}

Этап 3 · Сверка «поле → вывод»

Написан функциональный тест test_banner_output_matches_settings_fields: рендерит баннер через reflection с заполненными полями и проверяет, что значения из формы попадают в HTML, данные события не дублируются, а fallback + обрезка работают при пустых полях.

7 тестов

0 расхождений

Каждое поле формы читается и выводится в баннере

✓

Итог. Баннер полностью управляется из админки: заголовок, текст, кнопка, высота и обрезка анонса — всё через поля ввода. Чекбоксы полей удалены, механизм is_field_enabled() оставлен для совместимости (рендером не используется).
