Редизайн админки в стиле Clearfy Pro

Единый визуальный язык для всех страниц пункта меню «Иду по городу»: современные toggle-переключатели, карточки-секции с иконками, вкладки-чипы и статус-индикаторы вместо стандартной админки WordPress.

Ключевые элементы

Toggle 44×24

Крупный переключатель с плавной анимацией слайда (0.25s). Серый #c4c4c4 → синий акцент #165ff4. Бегунок с тенью.

Карточки-секции

Белые панели с мягкой тенью и радиусом 8px. В шапке — иконка в цветном квадрате, заголовок и описание.

Вкладки-чипы

Иконка Dashicons + подпись, закругление 4px, тень при активной вкладке. Переключение без перезагрузки (ссылки ?tab= остаются рабочими).

Статус-индикаторы

Метки «Вкл/Выкл» с цветной точкой: зелёный для активных, серый для выключенных.

Строка настройки

Все настройки сведены к единому паттерну «подпись слева (200px) / тело справа» — как в Clearfy Pro:

Разметка строки
<div class="idpg-ui-row">
	<div class="idpg-ui-row__label">
		<span>Название настройки</span>
	</div>
	<div class="idpg-ui-row__body">
		<!-- элемент управления + описание -->
		<p class="description">Пояснение</p>
	</div>
</div>

Файлы стиля

ФайлСодержимое
assets/css/admin-ui.cssОбщий слой: токены, toggle, статусы, карточки, кнопки, уведомления, адаптация виджет-менеджера темы. Скоуп .idpg-admin-ui
assets/css/settings.cssСпецифика страницы настроек: вкладки-чипы с иконками, заголовок с логотипом, sticky-панель сохранения, кнопки экспорта/импорта/сброса

Покрытие страниц

  • Иду по городу (idpg-settings) — вкладки «Области виджетов» и «Экспорт / О плагине»
  • Конфиденциальность (idpg-privacy) — cookie-баннер, запросы субъектов ПДн
  • Отклонить событие (idpg-reject-event) — модерация
  • Области виджетов (idpg-widget-areas-manage) — собственная страница в том же стиле
i

Общий слой подключается через enqueue_admin_ui() по списку хуков IDPG_Settings_Page::admin_ui_hooks() — новая страница автоматически получает оформление после добавления своего хука в массив.
