## 1. Проблема и цель

**Проблема.** Страница управления областями виджетов живёт в теме (`inc/widget-areas.php`),
оформлена собственным «карточным» UI (`idpg-wa-*`), лежит подменю в «Внешний вид»,
и визуально не совпадает с эталоном, принятым владельцем.

**Цель.** Переписать **только админ-интерфейс** страницы:

1. Перенести страницу в **новое верхнее меню «IDPG»** (подпункт «Области виджетов»).
2. Повторить UI/UX страницы настроек **Clearfy Pro 3.7.3** (установлен локально,
   `plugins/clearfy-pro`) — «один в один» по разметке и стилям:
   заголовок, ряд кнопок, табы, белая карточка с полями «подпись / контрол /
   знак », правая колонка с боксами, залипающая панель сохранения.

**Поведение, хранение данных и фронтенд-вывод НЕ меняются** (выбор владельца).

## 2. Решение

### 2.1. Меню

- `add_menu_page( 'IDPG', 'IDPG', 'manage_options', 'idpg-widget-areas',
  'idpg_widget_areas_admin_page', 'dashicons-welcome-widgets-menus', 61 )` —
  верхний пункт «IDPG» после «Внешний вид».
- `add_submenu_page( 'idpg-widget-areas', …, 'Области виджетов', … )` — подпункт.
- Старая регистрация под `themes.php` удаляется. URL меняется на
  `admin.php?page=idpg-widget-areas`; slug сохраняется (обратная совместимость параметров).
- `idpg_widget_areas_admin_assets()` — проверка хука `toplevel_page_idpg-widget-areas`.
- Редиректы обработчика и ссылка в напоминании на экране «Виджеты» переводятся
  на новый URL, добавляется параметр вкладки.

### 2.2. Разметка страницы (эталон — `clearfy-admin.php` Clearfy Pro 3.7.3)

- Оболочка: `.wrap.idpg.idpg-settings-page.js-idpg`, `<h1>IDPG</h1>`.
- `<h3>` «Области виджетов»; уведомления — штатные `notice notice-success`.
- Ряд кнопок: `.idpg-pseudo-button` («Добавить область» — вкладка формы,
  «Управлять виджетами» — ссылка на `widgets.php`), подсказка про экран «Виджеты»
  и строка «Не забудьте сохранить настройки».
- Две колонки `.idpg-settings-cols`; левая — табы + карточки вкладок,
  правая (300px) — боксы «Версия темы» и «Полезные ссылки».
- Табы: `h2.idpg-tab-wrapper` + `a.idpg-tab`; активный — `.idpg-tab-active`;
  контент — `.idpg-tab-in` (`.active`). Вкладки: «Список областей» и
  «Добавить область» / «Редактировать область». Активная вкладка: приоритет
  у `?tab=`; без него JS восстанавливает вкладку из cookie `tab-idpg`
  (PHP по умолчанию открывает список, при `?edit=` — форму).
- Поля формы: `.idpg-option-field` (position relative, `padding-right 24px`) →
  `.idpg-option-field-label` (28%) + `.idpg-option-field-body`, знак «?» —
  `span.idpg-ico-help` (24px, кружок 2px #165ff4, абсолютно справа в строке,
  подсказка в `title`), описание — `p.description`.
- Селекты — нативные (`<select>`), как в эталоне; старый кастомный селект
  (`idpg_widget_areas_select()`) больше не вызывается, но функция сохраняется.
- Панель сохранения `.idpg-save-container` — залипающая снизу карточки формы
  (`position: sticky`), кнопка `submit_button()` + ссылка «Отмена» при правке.
- Список областей: строки `.idpg-area` (иконка, название, бейджи позиции/показа,
  раскрывающийся список страниц, действия «Редактировать» / «Удалить»),
  пустое состояние `.idpg-areas-empty`.
- Каждое действие «Удалить» — отдельная форма (nonce, `idpg_area_action=delete`,
  `idpg_area_slug`), как раньше; основная форма оборачивает только вкладку формы.

### 2.3. Стили (`assets/css/widget-areas-admin.css` — полная переработка)

Токены и метрики скопированы по значениям из `plugins/clearfy-pro/admin/css/clearfy-admin.css`
(GPL-совместимое использование; проприетарные ассеты/логотипы не переносятся):

| Токен | Значение |
|---|---|
| Основной текст страницы | `#19193d` |
| Акцент (табы, заголовки секций, ссылки, знак «?») | `#165ff4` |
| Зелёный «рекомендовано» (резерв, сейчас не используется) | `#179347` |
| Разделители | `#e5e5e5`; вкладка неактивная `#fbfbfb` / `#e6e6e6` / `#ccc` |
| Карточка/виджеты | фон `#fff`, тень `0 1px 3px rgba(153, 144, 198, .2)`, радиус `.5rem` |
| Карточка вкладки | padding `35px 25px 25px`, радиус `0 .5rem .5rem .5rem` |
| Заголовок секции | `1.3em/600`, цвет `#165ff4`, `margin 0 0 30px` |
| Поле | `flex`, колонка → строка ≥768px (`gap 2rem`), подпись 28%, `padding-right 24px` (место под знак «?») |
| Табы | `14px/24px`, `padding 7px 12px`, активная — белая с верхней границей `2px #165ff4` |
| Панель сохранения | `padding 20px 25px`, `border-top 1px #e5e5e5`, тень `0 -10px 20px -20px rgba(0,0,0,.2)`, `position: sticky; bottom: 0` |
| Кнопки-псевдо | `border 2px #6da8e1`, `padding 7px 20px`; серый вариант `#77939f`; опасный `#dd2b19` |
| Колонки | `flex`, колонка → строка ≥1200px, `gap 2rem`; правая `300px`, `padding-top 20px` |

Отличие от эталона (осознанное): залипание панели сохранения через CSS сразу,
у Clearfy — через JS после первого изменения полей.

### 2.4. JS

Инлайн-скрипт в разметке (как было): табы (клик, cookie, `?tab=`), показ поля
«Страницы» только для условия «Конкретные страницы» (существующая логика),
раскрытие списка страниц у области, подсветка выбранных страниц.

## 4. Границы (что НЕ делаем)

- Не меняем опцию `idpg_widget_areas`, её формат и хранение.
- Не трогаем `idpg_widget_areas_render()`, регистрацию сайдбаров, условия показа,
  фронтенд-шаблоны и SCSS фронта.
- Не добавляем новых настроек/тумблеров; кнопки-псевдо — только навигационные.
- Не копируем проприетарные ассеты и логотипы Clearfy Pro; берём только значения
  токенов из установленной копии (GPL-совместимо для free-части, значения — факты).
- Не удаляем хелпер `idpg_widget_areas_select()` (не используется после редизайна,
  сохранён по правилу «не удаляй»); его старые стили `.idpg-wa-select*` удаляются
  вместе с редизайном.
- Не создаём новых файлов, кроме теста `test-widget-areas-admin-page.php` и этой спеки.
- Не трогаем другие экраны админки и тумблеры Clearfy (плагин-сосед).

## 6. Обратная проба

- **Замер «до»:** старый файл перезаписан; вместо прогона на нём выполнены мутации
  ниже — каждая роняет соответствующий тест, значит тесты ловят именно новые
  элементы (меню, маркеры, токены), а не текущее поведение.
- **Замер «после»:** все тесты файла — зелёные (14 тестов / 61 утверждение); полный прогон плагина — 502 теста / 1371 утверждение / 1 skip (было 498/1353 до добавления функциональных).
- **Мутации (прогнано, все пойманы):**
  1. вернуть `themes.php` в редирект → `test_legacy_appearance_bindings_removed` +
     `test_redirects_keep_tab_state` (2 падения);
  2. заменить `add_menu_page(` → `test_menu_is_top_level_idpg`;
  3. заменить `#165ff4` в CSS → `test_css_uses_clearfy_tokens`;
  4. убрать `position: sticky` из CSS → `test_css_uses_clearfy_tokens`;
  5. переименовать `idpg-save-container` в PHP → `test_clearfy_layout_markup`
     (первая версия теста это пропустила — маркер совпадал как подстрока
     `js-idpg-save-container`; проверка усилена до точных фрагментов разметки);
  6. заменить `wp_verify_nonce(` → `test_behavior_contract_untouched`.
- **Подтверждение отсутствия регрессий:** полный PHPUnit — 498 / 1353 / 1 skip
  (было 488 / 1310 / 1 skip; +10 тестов DEV-273), падений нет; PHPCS файла темы
  и теста — exit 0. Устаревшие записи baseline темы для `inc/widget-areas.php`
  обновлены (исчезнувшие нарушения убраны, count несовпадений актуализированы).
- **Глазами:** владелец сверяет страницу со скриншотом Clearfy Pro 3.7.3.
